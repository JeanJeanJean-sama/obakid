# データファイルの書き方（v0.3.0 時点）

`v0.3/data/` のファイルを書き換えると、プログラムを触らずに、名前・セリフ・マップ・調整用の数値を変えられます。

## 書き換えたあとの確かめ方

1. ファイルを保存する
2. ブラウザでゲームのページを再読み込みする（F5 キー）
3. 画面に「data/〇〇.json が読み込めませんでした」と出たら、書き方の間違いです（下の「よくある間違い」を見てください）

## ファイルの一覧

| ファイル | 中身 |
|---|---|
| characters.json | キャラクターの名前と、使う画像の名前 |
| dialog.json | すべてのセリフ・説明文・画面の文字 |
| obakid.json | 図鑑の内容 |
| settings.json | 調整用の数値（モップの回数、ハートの数、ペロッパの速さなど） |
| maps/plaza.json | 広場のマップ |
| events.json | イベントの台本（書き方は `docs/event-script.md`） |
| assets.json | 画像と音のファイルの一覧（くわしくは `docs/asset-list.md`） |

`"_説明"` と書かれた行は、人間向けのメモです。ゲームは読みません。

## JSON の書き方の基本

```json
{
  "name": "ハナさん",
  "lines": [
    "1つ目",
    "2つ目"
  ]
}
```

- 文字は `"` でかこむ
- 並べるときは `,`（カンマ）で区切る。**最後の1つの後ろにはカンマを付けない**
- `{ }` と `[ ]` は、開いた数と閉じた数を同じにする
- 数字は `"` でかこまない（`"uses": 4`）
- `true`（はい）と `false`（いいえ）も `"` でかこまない

### よくある間違い

| 間違い | 正しい |
|---|---|
| `"a", "b",]` （最後にカンマ） | `"a", "b"]` |
| `"a" "b"` （カンマ忘れ） | `"a", "b"` |
| `「ハナさん」` を `"` の代わりに使う | 半角の `"` を使う |
| セリフの中に `"` を書く | `\"` と書くか、`「」` を使う |

## characters.json：名前を変える

```json
"hana": { "name": "ハナさん", "image": "hana" }
```

- `name` を変えると、頭の上の名前と、セリフの中の `{hana}` がまとめて変わります
- `image` は `assets.json` の画像の名前です

## dialog.json：セリフを変える

セリフは「誰が・どの場面で」話すかで名前を付けて整理しています。

| 名前 | 中身 |
|---|---|
| hana.first / takeru.first | 最初に話したとき |
| hana.afterMop / takeru.afterMop | モップを手に入れたあと |
| hana.boss / takeru.boss | ペロッパとの勝負中 |
| hana.done / takeru.done | 捕まえたあと |
| objects.〇〇 | 物置・看板・木・水路・木箱・マンホールを調べたとき |
| system.〇〇 | 冒頭、やり直し、捕まえたときなどの文 |
| events.peroAppear.〇〇 | ペロッパ登場イベントのセリフ |
| hud.〇〇 | 画面の上に出る目標の文 |
| popups.〇〇 | ふわっと出る短い文字（「ツルッ！」など） |
| zukan.〇〇 | 図鑑の見出し |

- `[ ]` の中の `"..."` 1つが、Z キーで送る1画面ぶんです。増やしたり減らしたりできます
- 1画面に入るのは、だいたい 30 文字×3 行までです
- `{ }` でかこんだ言葉は、自動で置きかわります

| 書き方 | 置きかわるもの |
|---|---|
| {player} {hana} {takeru} {pero} | characters.json の名前 |
| {mopMax} | モップを使える回数（settings.json） |
| {left} | 残りのワックスだまりの数（hud.wipe だけで使える） |

## obakid.json：図鑑の内容

| 項目 | 中身 |
|---|---|
| id | プログラムが使う名前（変えない） |
| no | 図鑑の番号 |
| character | characters.json の名前（絵と名前に使う） |
| name / category / habitat | 名前・分類・出現場所 |
| description | 説明文 |
| memo | 捕獲メモ |

## settings.json：調整用の数値

| 場所 | 項目 | 意味 | いまの値 |
|---|---|---|---|
| player | hearts | ハートの数 | 3 |
| player | invincibleSec | ダメージのあと無敵になる秒数 | 1.2 |
| player | walkMs / slideMs | 1マス歩く・滑る時間（ミリ秒） | 130 / 60 |
| player | turnHoldSec | これより短く押すと向きだけ変わる（秒） | 0.12 |
| player | showFacingDot | 向きを示す黄色い点を出すか | true |
| mop | uses | モップを使える回数 | 4 |
| dialog | charsPerSec | 1秒に出る文字数 | 45 |
| dialog | blipEvery | 何文字ごとに文字送りの音を鳴らすか | 2 |
| spit | intervalSec | ペロッパがワックスを飛ばす間隔（秒） | 4.5 |
| spit | flightSec | 塊が落ちるまでの秒数 | 1.1 |
| boss | hp | 捕まえるのに必要な回数 | 3 |
| boss | chaseChance | 主人公にそろいに来る確率（0〜1） | 0.6 |
| boss | trailSec | 通った跡のワックスが残る秒数 | 6 |
| boss | telegraphSec | 突進の前の「！」の秒数 | 0.75 から捕まえるたびに 0.15 短く（最短 0.35） |
| boss | wanderStepSec | うろうろ歩く間隔 | 0.45 から 0.08 ずつ短く（最短 0.22） |
| boss | dizzySec | 目を回している秒数 | 2.6 から 0.3 ずつ短く（最短 1.6） |
| boss | cooldownSec | 次に突進できるまでの秒数 | 場面ごとに 4 つ |

- `start`・`perLevel`・`min` の3つがある数値は、「最初の値＋捕まえた回数×perLevel、ただし min より小さくならない」という意味です
- **モップの回数（mop.uses）やマップを変えたら、必ずパズル検証をやり直してください**（README.md の「パズルを検証する」）

## maps/plaza.json：マップ

`rows` の1文字が1マスです。横20マス×縦15マス（画面いっぱい）で作ってください。

| 文字 | 意味 |
|---|---|
| `.` | 床 |
| `E` | 広場の入口（床と同じ） |
| `#` | 壁 |
| `S` | 物置（調べるとモップ） |
| `s` | 看板 |
| `T` | 木 |
| `W` | 水路（滑って入ると落ちる） |
| `~` | ワックス |
| `O` | ワックスだまり（全部拭くとペロッパ登場） |
| `C` | 木箱（下はワックス） |
| `M` | マンホール（1つだけ） |
| `A` / `B` | ハナさん / タケルの立つ場所 |
| `P` | 主人公のスタート地点 |

文字の意味は同じファイルの `legend` に書いてあり、そこで新しい文字を増やすこともできます。

| legend の項目 | 意味 |
|---|---|
| tile | 使うタイル画像（`tile_〇〇` の 〇〇 の部分） |
| solid | 通れない |
| canal | 水路 |
| wax / source | ワックス / ワックスだまり |
| crate | 木箱を置く |
| manhole | マンホール |
| npc | 住人の立つ場所（characters.json の名前） |
| playerStart | 主人公のスタート地点 |
| examine | 調べたときのセリフの種類（shed・sign・tree・canal・manhole） |

そのほかの項目は次のとおりです。
- `arena`：ペロッパが動き回れる範囲
- `bossRetryStart`：勝負をやり直すときの主人公の位置
- `labels`：マップの上に出す文字
