# オバキッド捕獲作戦　企画・設計メモ

最終更新：v0.3.0 時点（v0.4 以降の構想を追記）

## コンセプト

1989年にカネボウ（現クラシエ）から発売された「スーパーおばキッド」のカードを題材にした、非公式のファン制作ゲーム。
ポケモンのように、さまざまなオバキッドを見つけて捕まえ、図鑑を埋めていく。
ただしバトルで弱らせるのではなく、カードの説明文に書かれた性質をヒントに「捕まえ方を推理し、アクションで捕まえる」のが特徴。

題材は「君はオバキッドを見たか⁉️」シリーズ。いたずらをする宇宙からきた妖怪が日常にひそみ、裏でチームに分かれて「オバキッドカップ」という競技をしている、という世界観を踏襲する。

> 物語の詳細（ネタバレを含む）は、非公開の資料にまとめている。この書類には、遊び始めてすぐにわかる表向きの設定だけを書く。

## 遊びの基本の流れ

1. 町を探索し、住人の話や異変（手がかり）を集める
2. どのオバキッドの仕業か、どうすれば姿を現すかを推理する
3. 道具を使ってパズル的な仕掛けを解き、オバキッドをおびき出す
4. アクション（ゼルダの伝説のボス戦のような形）で捕まえる
5. 図鑑に登録される。特別なオバキッドなら仲間になり、その能力が使えるようになって、行ける場所が増える

## ゲームの柱

- **仲間と能力**：能力は主人公のものではなく、仲間のオバキッドの力を借りて使う。使うときはそのオバキッドが一瞬出てきて手伝う
- **特別なオバキッド 5体・能力 5つ**：アクション寄り3つ、探索・推理寄り2つ。ただし、どの能力もパズルと勝負の両方で使える（例：ペロッパのワックスは、パズルでは自分が滑る道を作り、勝負では相手を滑らせて壁にぶつける）。グループの内訳はこれから決める（ペロッパはグランDズ）
- **能力の操作**：能力ボタン1つ＋切り替えボタンで、仲間の能力をいつでも選べる
- **通常のオバキッド**：町の中の専用エリア（パズルフィールド）で謎を解くと仲間にできる。v1.0 の目標は20体（最低15体）。あとから増やせる作りにする。寄り道として遊べ、捕まえなくても先に進める
- **通常のオバキッドのメリット**：捕獲戦や勝負が楽になる強化だけにする（例：3体ごとにハート+1）。謎の難しさが変わる強化（モップの回数など）は入れない
- **勝負の形**：基本のルール（マス目・操作・ハート）は共通にする。特別なオバキッドとの勝負は、見せ方と演出で毎回別のゲームのように感じさせる（レース風、かくれんぼ風など）。ラスボス戦だけ演出の色合いを変える

## 世界とマップ

- 全体マップは1つの町を、いくつかの地区（住宅地・学校・商店街など）に分けたもの。ゼルダの伝説やポケモンのように歩き回り、人と話して手がかりを集める
- 謎解きと勝負は、マンホールの中・部屋・学校の教室などの「パズルフィールド」で行う。今の「マンホール広場」が1つ目
- 全体マップにも、能力が無いと通れない道を少し置き、能力が増えるたびに行ける場所が広がるようにする

## ストーリー

表向きの設定（遊び始めてすぐにわかる範囲）だけを書く。物語の詳細は非公開の資料（`private/STORY.md`。GitHub には上げない）にある。

- 主人公は博士に頼まれ、町にひそむオバキッドを捕まえて図鑑を集める
- 地球では、グランDズ（地上で活動するグループ）とジャンPズ（空中で活動するグループ）がオバキッドカップを行っている
- グランDズのリーダー、キャプテン・エルリアンが、ライバルとして主人公の前に現れる
- OBA星王・ゴンと、OBA星女王・ソフィアは、オバキッドカップの主催者

## 1体目：ペロッパ（v0.2.0 で実装済み）

- 設定：マンホールにひそみ、舌から出すワックスで何でもツルツルにする
- 舞台：ひかり町のマンホール広場
- 名前「ペロッパ」は正式な名前とする（図鑑の「（仮）」は外す）
- パズル：ワックスの上では、障害物か乾いた床に入るまで止まれない（氷の床パズル）
  - 広場に「ワックスだまり」が3つ。全部拭くとペロッパが出現
  - モップは4回しか使えない（ワックスだまり3つ＋自由に1回）
  - 木箱を押すとワックスの上を滑り、止まるための壁代わりになる
  - 配置は総当たりの検証プログラムで、4回ちょうどで解ける・3回では解けない・木箱なしでは解けないことを確認済み
  - v0.3.0 で検証プログラムを `v0.3/tools/verify-puzzle.js` として残した。ゲームと同じルールのファイルを使い、水路に落ちる場合（ハートが残っているあいだ）も含めて調べる
- 妨害：パズル中、ペロッパがワックスの塊を飛ばす（落下地点に影が出る）
- 登場：最後のワックスだまりを拭くとイベントになる。マンホールが揺れ、ワックスが乾き、タケルが網を渡しに来る（v0.3.0 から台本で動かしている）
- 捕獲：ペロッパの体はツルツルで網がすべる。同じ列・行にそろうと突進してくるので、壁や木箱に当てて目を回させ、虫取り網で捕まえる。3回で捕獲、捕まえるたびに速くなる
- ペナルティ：ハート3つ。水路に落ちる・ワックスに当たる・突進を受けると減る。0で広場（または勝負）をやり直し

## 操作

- 移動：矢印キー / WASD（軽く押すとその場で向きだけ変わる）
- Z / Space：話す・調べる・決定
- X：モップで拭く（目の前、無ければ足元）
- C：虫取り網を振る
- R：広場をやり直す

## 登場人物

名前は `data/characters.json` で変えられる。

- 主人公：名前未定（データ上は仮に「主人公」）
- ハナさん：町の住人。滑る床のルールのヒントをくれる
- タケル：町の少年。ワックスだまりや木箱のヒントをくれ、ボス戦で網を渡してくれる

## 作りの仕組み（v0.3.0 から）

v0.3.0 で、絵・音・文章・数値をプログラムから切り離した。

| 変えたいもの | 置き場所 | 説明書 |
|---|---|---|
| 絵 | `assets/images/` に決まった名前の PNG を置く | docs/asset-list.md |
| 音 | `assets/audio/` に決まった名前の MP3 を置く | docs/asset-list.md |
| 名前・セリフ・図鑑 | `data/characters.json`・`dialog.json`・`obakid.json` | docs/data-guide.md |
| 調整用の数値 | `data/settings.json` | docs/data-guide.md |
| マップ | `data/maps/plaza.json` | docs/data-guide.md |
| イベントの流れ | `data/events.json` | docs/event-script.md |

- 無い画像は仮の図形で代用し、無い音は鳴らさない。描けた絵から1枚ずつ差し替えていける
- 絵の作業ファイル（描きかけ・お絵描きソフトの保存ファイル・下書き）は `art/` に置き、GitHub には上げない。版のフォルダには、完成してゲームで使う PNG だけを置く。ネタバレになる絵は、作業ファイルも完成品も `private/art/` に置く
- タイルとキャラの1コマは 32×32 ピクセルに決定。拡大・縮小はせず、描いた大きさのまま表示する
- キャラの画像は「横に歩くコマ、縦に向き（下・左・右・上）」の並べ方にする
- マス目の移動と滑るルールは `js/systems/grid.js` にまとめ、ゲームとパズル検証プログラムの両方で使う
- 手元で動かすにはローカルサーバーが必要（README.md の「手元で遊ぶ」）

## 制作のルール

- 技術：Phaser 3.80.1（lib フォルダに同梱）、GitHub Pages で公開。v0.2 までは各版が HTML ファイル1つ、v0.3 からは版のフォルダの中にプログラム・データ・素材のファイルを分けて置く
- 絵：オバキッドのドット絵は作者が描く。それまでは仮の図形を使う。カード画像は取り込まない
- 文章：カードの文章はそのまま使わず、設定を参考に自分の言葉で書く
- 差し替えやすさ：キャラの名前・絵・文章は、プログラムを触らずに差し替えられるようにする（v0.3.0 で実現）
- パズル：配置やルールを変えたら、検証プログラムで解けることを確かめる
- 版の番号：セマンティックバージョニング（README.md 参照）
- 公開の流れ：作業は GitHub のリポジトリのフォルダで直接行い、版ができたら作者が GitHub Desktop でコミット・タグ付け・Push する（くわしくは CLAUDE.md）
