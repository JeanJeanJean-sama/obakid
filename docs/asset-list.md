# 画像と音の注文書（v0.3.0 時点）

ゲームで使う画像と音の一覧です。ドット絵や音を作るときは、この表の**ファイル名**と**大きさ**で作ってください。

- 置き場所：画像は `v0.3/assets/images/`、音は `v0.3/assets/audio/`
- 無いファイルは、画像なら仮の図形、音なら鳴らさないだけです。できたものから1つずつ置いていけます
- 一覧の元データは `v0.3/data/assets.json` です。ファイル名や大きさを変えたいときは、そちらを書き換えます

> 1マス・1コマの大きさは 32×32 ピクセルに決まりました。

## 画像の共通ルール

- 形式：PNG
- 背景：タイル（床・壁・水路など）以外は**透明**にする
- ドット絵がぼやけないように、ゲームは拡大・縮小しても角をくっきり表示する設定にしています

## キャラクター（アニメーション用の並べ方）

キャラクターは、1枚の画像にコマを並べます。

- 1コマの大きさ：32×32
- 横方向：歩くコマ（`framesPerDirection` の数だけ）
- 縦方向：向き（上から 下・左・右・上 の順）

例：歩くコマが3つなら、画像全体は **横 96 × 縦 128** ピクセルになります。

```
         1コマ目  2コマ目  3コマ目
下向き   [    ]  [    ]  [    ]
左向き   [    ]  [    ]  [    ]
右向き   [    ]  [    ]  [    ]
上向き   [    ]  [    ]  [    ]
```

- 1コマ目が「止まっているときの絵」になります
- コマ数を変えたら、`data/assets.json` のそのキャラの `framesPerDirection` も同じ数にしてください（いまは 1）
- 歩くときの速さは `walkFps`（1秒に何コマ進むか）で変えられます

## 音や画像を作るための道具の例

- ドット絵：Aseprite、Piskel（ブラウザで使える）、Dotpict（スマホ）
- 効果音：jsfxr（ブラウザで使える）
- BGM：BeepBox（ブラウザで使える）

素材サイトのものを使う場合は、利用規約（クレジット表記が必要か、改変してよいか）を確認し、README.md のクレジットに書き足してください。
