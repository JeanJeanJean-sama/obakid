# イベントの台本の書き方（v0.3.0 時点）

キャラを歩かせたり、セリフを出したり、画面を揺らしたりする場面を、`v0.3/data/events.json` に「台本」として書けます。
台本は、命令を上から順番に1つずつ実行します。

## 例：ペロッパ登場の場面（いまの台本の一部）

```json
"peroAppear": [
  { "do": "say", "text": "events.peroAppear.wiped" },
  { "do": "sound", "key": "se_rumble" },
  { "do": "shake", "sec": 0.6, "power": 0.006 },
  { "do": "walk", "who": "takeru", "to": [7, 10] },
  { "do": "call", "name": "spawnBoss" }
]
```

1. セリフ「最後のワックスだまりを拭き取った！」を出す
2. ゴゴゴという音を鳴らす
3. 画面を 0.6 秒揺らす
4. タケルを横7・縦10 のマスまで歩かせる
5. ペロッパを登場させる

## 命令の一覧

| 命令 | 書き方 | すること |
|---|---|---|
| say | `{ "do": "say", "text": "events.peroAppear.cry" }` | セリフを出す。`text` は `dialog.json` の中の名前。Z キーで読み終わると次へ進む |
| wait | `{ "do": "wait", "sec": 0.5 }` | 指定した秒数だけ待つ |
| shake | `{ "do": "shake", "sec": 0.4, "power": 0.01 }` | 画面を揺らす。`power` は強さ（0.005 で小さく、0.02 で大きく） |
| walk | `{ "do": "walk", "who": "takeru", "to": [7, 10] }` | キャラを指定のマスまで歩かせる。先に横、次に縦に進む。壁は気にせず通り抜けるので、道を選んで書く。`"ms": 200` を足すと1マスの時間を変えられる |
| face | `{ "do": "face", "who": "takeru", "dir": "down" }` | キャラの向きを変える。`dir` は up・down・left・right |
| sound | `{ "do": "sound", "key": "se_rumble" }` | 効果音を鳴らす。`key` は `assets.json` の名前 |
| bgm | `{ "do": "bgm", "key": "bgm_boss" }` | BGM を変える |
| stopBgm | `{ "do": "stopBgm" }` | BGM を止める |
| call | `{ "do": "call", "name": "spawnBoss" }` | プログラムに用意した処理を呼ぶ |

### `who` に書けるキャラ

- `player`（主人公）
- `hana`（ハナさん）
- `takeru`（タケル）

### `call` で呼べる処理（v0.3.0 時点）

| name | すること |
|---|---|
| dryWax | 広場のワックスを全部乾かす |
| giveNet | 虫取り網を持たせる |
| spawnBoss | ペロッパを登場させ、勝負を始める |

新しい処理が必要になったら、プログラムの `js/scenes/TownScene.js` の `eventActions` に追加します。

## マスの番号の数え方

マップ（`data/maps/plaza.json` の `rows`）の左上が `[0, 0]` です。右へ行くほど横の数が、下へ行くほど縦の数が増えます。
例：主人公のスタート地点は `[5, 7]`、ハナさんは `[3, 4]`、タケルは `[3, 10]` です。

## 注意

- イベント中は、遊ぶ人は操作できません。最後の命令が終わると操作できるようになります
- 知らない命令や名前を書いても止まらず、その命令を飛ばして先へ進みます（ブラウザの開発者ツールの Console に注意が出ます）
- 台本の最後で歩かせたキャラは、その場所に残ります。元の場所に戻したいときは、戻る `walk` も書いてください
