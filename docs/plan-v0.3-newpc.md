# 作業メモ　新しいPCでの作業環境と、絵の作業ファイルの置き場所

## 目的

作業の場所を新しいPCに移しました。これからは **GitHub のリポジトリのフォルダ（このフォルダ）で直接作業します**。
それに合わせてルールを書き直し、あわせて、これから増えるドット絵の作業ファイルの置き場所を決めます。

**ゲームの中身（`v0.3/` のプログラム・データ・素材）は変更しません。** 版の番号も v0.3.0 のままです。

## 前提（作業前の状態）

- このフォルダ（新しいPCの `C:\GitHub\obakid`）は GitHub からクローンしたリポジトリで、`.git` があります
- 旧PCの作業フォルダにあった `private/`（STORY.md、spoiler-words.txt）は、Cowork がこのフォルダにコピー済みです
- 旧PCのフォルダと見比べて、ゲーム本体のファイルに違いが無いことを Cowork が確認済みです
- いまの CLAUDE.md には「このパソコンでは Git を使わない」「zip にまとめて別の PC に渡す」という、旧PCのときのルールが残っています

## 作業の範囲

### やること

1. **CLAUDE.md の「Git と GitHub のルール」を書き直す**
   - 旧PCのときのルールを消す
     - 「このパソコンでは Git を使わない」
     - 「リポジトリは別の PC にあり…」
     - zip にまとめて渡す手順（zip の中身の決まりを含む）
   - かわりに次のルールにする
     ```
     - このフォルダは GitHub のリポジトリ（クローン）。ここで直接作業する
     - 変更の状態を確かめる操作（git status、git diff、git log）は、自由に行ってよい
     - コミット・タグ付け・Push は、作業者が GitHub Desktop で行う。作業が終わったら、コミットのメッセージの案を日本語で示す
     - .gitattributes（改行の設定）は消さない、変更しない
     - GitHub への送信（push）や公開に関わる操作は、必ず作業者の許可を取ってから行う
     - このフォルダに入れたものは、.gitignore で除外したものを除いて GitHub で公開される。公開してよいものだけを置く
     - ファイルの削除が必要なときは、事前に作業者の許可を取る
     ```
   - 「フォルダと版のルール」の `private/` の説明から「zip にも入れない」を消す（zip を作らなくなるため）
2. **絵の作業ファイル用のフォルダ `art/` を作る**
   - フォルダの一番上（`index.html` と同じ場所）に `art/` を作る
   - `art/README.md` を作り、次のことを短く書く
     - ここは、ドット絵の描きかけ・お絵描きソフトの保存ファイル（.aseprite など）・下書きを置く場所
     - GitHub には上げない
     - 完成してゲームで使う PNG は、`docs/asset-list.md` の名前と大きさで、版のフォルダの `assets/images/` に置く
     - ネタバレになる絵（まだ公開しないキャラなど）は、作業ファイルも完成した PNG も `private/art/` に置く
   - ※ `art/README.md` そのものも GitHub には上がりません（フォルダごと除外するため）。それで構いません
3. **`.gitignore` に `art/` を追加する**
   - 今の中身の下に、次を追加する
     ```
     # 絵の作業ファイル（GitHub に上げない）
     art/
     ```
4. **CLAUDE.md の「作り方のルール」に追加する**
   ```
   - 絵の作業ファイルは art/（ネタバレになるものは private/art/）に置く。版のフォルダには、完成してゲームで使う PNG だけを置く
   ```
5. **README.md の「フォルダ構成」に追加する**
   ```
   art/                絵の作業ファイル（GitHub には上げない）
   ```
   - `docs/` の一覧に `plan-v0.3-newpc.md　新しいPCでの作業環境の作業メモ` を追加する

### やらないこと

- `v0.1/`、`v0.2/`、`v0.3/` の中身の変更
- `private/` の中身の変更
- CHANGELOG.md とトップページの開発日記の変更（遊びの内容は変わらないため）
- コミット・タグ付け・Push（作業者が GitHub Desktop で行う）

## 作業が終わったら

`git status` の結果を作業者に見せて、次のことを確かめてもらってください。

- 変更の一覧に `private/` と `art/` の中身が**出ていない**
- 変わったのは `.gitignore`、`CLAUDE.md`、`README.md`、`docs/plan-v0.3-newpc.md` の4つだけ

コミットのメッセージの案：
```
新しいPCでの作業ルールに更新、絵の作業ファイル用の art/ を追加
```

## 確認してほしいこと

- CLAUDE.md から、zip を作るルールと「Git を使わない」ルールが消えている
- `.gitignore` に `private/` と `art/` の2つがある
- `art/README.md` がある
- ゲーム（`v0.3/`）がこれまでどおり起動して、最後まで遊べる
