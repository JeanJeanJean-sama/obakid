# 作業メモ　v0.3.0 公開の準備：ネタバレを公開しない仕組み

## 目的

v0.3.0 を GitHub で公開する前に、物語のネタバレを含む書類を公開対象から外す仕組みを作ります。
ネタバレを含む書類は `private/` フォルダに置き、GitHub に上げず、zip にも入れません。

**ゲームの中身（`v0.3/` のプログラム・データ・素材）は変更しません。** 版の番号は v0.3.0 のままです（まだ公開していないため）。

## 前提（作業前の状態）

- Cowork が、次のファイルを作成・更新済み（作業者が確認済み）
  - `private/STORY.md`：物語の詳細（ネタバレ）。`docs/DESIGN.md` から移した
  - `private/spoiler-words.txt`：ネタバレ確認に使う言葉の一覧
  - `docs/DESIGN.md`：ネタバレ部分を取り除き、表向きの設定だけにした
  - `docs/release-check.md`：版を公開する前のネタバレ確認の手順
- Cowork が事前に確認した結果、`v0.3/` の中（data・js・index.html・assets の README）にネタバレは見つからなかった

## 作業の範囲

### やること

1. **`.gitignore` を作る**
   - フォルダの一番上（`index.html` と同じ場所）に、`.gitignore` という名前のファイルを作る
   - 中身は次のとおり
     ```
     # ネタバレを含む非公開の資料（GitHub に上げない）
     private/
     ```
   - `.gitignore` は「Git に、このファイルやフォルダを無視させる」ための設定ファイル。GitHub Desktop の変更一覧にも出なくなる
2. **zip の作り方を変える**
   - zip に `private/` を**含めない**
   - zip に `.gitignore` を**含める**（`.nojekyll` と同じく、名前が「.」で始まるファイルを入れ忘れないこと）
   - zip を作ったら、中身の一覧を作業者に見せ、`private/` が無いこと、`.gitignore` があることを報告する
3. **版のフォルダのネタバレを確認する**
   - `docs/release-check.md` の手順2（言葉の検索）を実行し、結果を作業者に報告する
   - Cowork の事前確認では見つかっていないので、取り除く作業は無い見込み。もし見つかったら、直す前に作業者に相談する
4. **CLAUDE.md にルールを追加する**
   - 「フォルダと版のルール」の節に、次を追加する
     ```
     - ネタバレを含む書類は `private/` に置く。`private/` は .gitignore で GitHub に上げない設定にしてあり、zip にも入れない
     - `private/` の内容を、版のフォルダや公開する書類（docs/、README.md、CHANGELOG.md、トップページ）に書き写さない
     - まだ公開しない場面のセリフ・イベント・絵・音は、版のフォルダに入れない。ファイル名にも、正体や展開がわかる言葉を使わない
     - 版を公開する前に、docs/release-check.md の手順でネタバレ確認を行う
     ```
   - 「Git と GitHub のルール」の zip の説明にも、「`private/` は入れない。`.gitignore` は入れる」と書き足す
5. **README.md を更新する**
   - 「フォルダ構成」に次の1行を追加する（`private/` については書かない）
     ```
     .gitignore          GitHub に上げないファイルの設定
     ```
   - 「docs/」の一覧に `release-check.md　公開前のネタバレ確認の手順` と `plan-v0.3-publish.md　公開準備の作業メモ` を追加する

### やらないこと

- `v0.3/` の中身の変更（ネタバレが見つかった場合は、作業者に相談してから）
- `v0.1/`、`v0.2/` の変更
- `private/` の中身の変更
- CHANGELOG.md とトップページの開発日記の変更（遊びの内容は変わらないため）
- GitHub への送信（コミット・タグ付け・Push は作業者が別の PC で行う）

## 作業者への案内（zip を渡すとき）

次のことを、手順として伝えてください。

1. 別の PC のリポジトリのフォルダに zip を展開して上書きする（`.gitattributes` は消さない）
2. GitHub Desktop の変更一覧に、`private` の中のファイルが**出ていない**ことを確かめる
3. `.gitignore` が新しく追加されていることを確かめる
4. コミットし、`v0.3.0` のタグを付けて Push する

コミットのメッセージの案：
```
v0.3.0 公開準備：ネタバレを含む資料を非公開にする仕組みを追加
```

## 確認してほしいこと（作業が終わったら）

- `.gitignore` がフォルダの一番上にあり、中身が上のとおりになっている
- zip の中に `private/` が無く、`.gitignore` と `.nojekyll` がある
- `docs/release-check.md` の言葉の検索で、公開するファイルから何も見つからない
- CLAUDE.md と README.md に、上の追加が入っている
- ゲーム（`v0.3/`）がこれまでどおり起動して、最後まで遊べる
