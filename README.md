# オバキッド捕獲作戦

ブラウザで遊べる、オバキッドを捕まえるゲームの制作記録です。v1.0.0 の完成をめざして開発中です。

## フォルダ構成

```
index.html        トップページ（版の一覧と開発日記）
v0.1/index.html   v0.1.0 最初の試作版
v0.2/index.html   v0.2.0（最新版）
lib/              ゲームエンジン Phaser 3.80.1 とそのライセンス
CHANGELOG.md      変更履歴
.nojekyll         GitHub Pages に余計な変換をさせないための空ファイル
```

## 版の番号の付け方

`v0.2.1` のような3つの数字で表します（セマンティックバージョニング）。

| 変わる数字 | 意味 | 例 |
|---|---|---|
| 左 | 大きな節目。1.0.0 が最初の完成版 | v0.9.0 → v1.0.0 |
| 真ん中 | 新しい要素の追加や、遊びの変更 | v0.2.0 → v0.3.0 |
| 右 | 誤字・バグの修正、難易度の微調整 | v0.2.0 → v0.2.1 |

遊べるフォルダは「真ん中の数字が変わる節目」ごとに作ります（`v0.1/`、`v0.2/` …）。
右の数字だけが変わる小さな修正は、そのフォルダの中身を上書きし、GitHub のタグと CHANGELOG.md に記録します。

## 手元で遊ぶ

VS Code の拡張機能「Live Server」でこのフォルダを開き、index.html を表示してください。

## 小さな修正をするとき（例：v0.2.0 → v0.2.1）

1. `v0.2/index.html` を直接修正する
2. ページ内の表記（`<title>` と見出し下の説明）を v0.2.1 に変える
3. CHANGELOG.md に「v0.2.1」の項目を追加する
4. GitHub Desktop でコミットし、そのコミットに `v0.2.1` のタグを付けて Push する

## 新しい要素を追加するとき（例：v0.3.0）

1. 最新版のフォルダ（`v0.2`）をコピーして `v0.3` にする
2. `v0.3/index.html` を編集し、ページ内の表記を v0.3.0 に変える
3. トップページ index.html の「最新版」リンクを `v0.3/` に変え、v0.2.x を「過去の版」に移す
4. CHANGELOG.md と、トップページの開発日記に変更内容を書く
5. GitHub Desktop でコミットし、`v0.3.0` のタグを付けて Push する
